# משק תורג'מן - יומן עבודה יומי

אפליקציית PWA (Progressive Web App) עצמאית ליומן עבודה יומי במשק, כולל
נוכחות עובדים, שעות עבודה, משימות לפי חלקה/מנהרה, הערות השקייה, לשונית
דוחות עם ייצוא ל-CSV/JSON והדפסה.

הנתונים נשמרים מקומית במכשיר (`localStorage`) - אין שרת/בקאנד, הכול
פועל בצד הלקוח בלבד.

## פיתוח

```bash
npm install
npm run dev
```

## בנייה

```bash
npm run build
npm run preview
```

## התקנה על מסך הבית (iPad / iPhone)

1. פתחו את כתובת האתר בדפדפן Safari.
2. הקישו על כפתור השיתוף (הריבוע עם החץ).
3. בחרו "הוסף למסך הבית".

האפליקציה תיפתח במסך מלא, ללא סרגל כתובות, ותעבוד גם ללא חיבור לאינטרנט
(לאחר טעינה ראשונה) הודות ל-Service Worker.
