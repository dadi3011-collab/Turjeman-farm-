# מה עוד חסר

1. **הודעות אמיתיות מלקוחות** (שאלה 7): 2 עד 3 הודעות וואטסאפ או מייל.
2. **שאלות המבחן** (שאלה 12): 3 שאלות שעובד חדש חייב לדעת לענות עליהן.
3. **דוגמאות כתיבה**: לפחות 3 קבצים ב-`knowledge/samples/` (הודעה ללקוח,
   הודעה לעובדים, סיכום או החלטה).
4. **הקול**: "אנחנו ___ אבל לא ___", משפט שרק אתה היית כותב, ומילים אסורות.
5. **קבצים קיימים**: רשימת ספקים, קבלות, הצעות מחיר, לתיקיית `inbox/`.
